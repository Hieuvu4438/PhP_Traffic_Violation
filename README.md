# Website Tra Cứu Phương Tiện Vi Phạm Giao Thông

Đồ án bài tập lớn PHP - Website tra cứu phạt nguội toàn quốc.

## Cài đặt

1. Copy toàn bộ thư mục vào `htdocs` của XAMPP
2. Import database:
   - Mở http://localhost/phpmyadmin
   - Import `database/schema.sql`
   - Import `database/seed.sql`
3. Cấu hình Apache DocumentRoot trỏ vào thư mục `public/`
4. Truy cập http://localhost/
