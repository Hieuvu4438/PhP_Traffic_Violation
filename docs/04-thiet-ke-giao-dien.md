## 1. BẢNG MÀU & TYPOGRAPHY

### 1.1. Bảng màu chủ đạo

| Tên | Mã màu | Sử dụng |
|-----|--------|---------|
| Primary | `#1a56db` (Xanh CSGT) | Navbar, buttons, links, headings |
| Primary Dark | `#1e40af` | Hover state buttons |
| Secondary | `#10b981` (Xanh lá) | Success badges, "Đã xử lý" |
| Warning | `#f59e0b` (Vàng) | "Đang xử lý", alert |
| Danger | `#ef4444` (Đỏ) | "Chưa xử lý", delete buttons |
| Gray 100 | `#f3f4f6` | Background nhạt |
| Gray 700 | `#374151` | Text body |
| Gray 900 | `#111827` | Headings, text chính |
| White | `#ffffff` | Card background, nền chính |

### 1.2. Typography

```css
/* Font chính */
font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;

/* Font tiếng Việt (fallback nếu Inter không hỗ trợ tốt) */
font-family: 'Be Vietnam Pro', 'Inter', sans-serif;

/* Kích thước */
h1: 28px | h2: 24px | h3: 20px | h4: 18px
body: 16px | small: 13px
```

## 4. RESPONSIVE BREAKPOINTS

| Breakpoint | Thiết bị | Layout thay đổi |
|------------|----------|-----------------|
| < 576px | Mobile | 1 cột, menu hamburger, card xếp dọc |
| 576px - 768px | Tablet dọc | 2 cột grid, navbar rút gọn |
| 768px - 992px | Tablet ngang | 2-3 cột grid |
| 992px - 1200px | Desktop nhỏ | 3 cột grid, sidebar admin thu gọn |
| > 1200px | Desktop lớn | 4 cột grid, đầy đủ tất cả |

